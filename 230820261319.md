## Зачем делается рефакторинг

Цель — убрать рассыпанные read/validate/write последовательности из route handlers и заменить их явными domain boundaries с PostgreSQL-транзакциями. Каждая операция должна:

1. проверить provider/user/domain identity;
2. захватить locks в стабильном порядке;
3. вычислить полный результат до SQL mutation;
4. записать все эффекты и terminal status одной транзакцией;
5. отправить notification только после commit;
6. безопасно переживать callback replay и конкуренцию.

Production не является тестовым контуром. Новые slices сначала проходят unit tests, isolated PostgreSQL races, full regression, independent review и controlled dev E2E.

## Архитектурный шаблон

### Payments

```text
provider payment/ledger claim
→ users FOR UPDATE
→ catalog/inventory/bank/premium mutation
→ legacy provider log, если нужен
→ terminal succeeded
→ COMMIT
→ WebSocket notification
```

YooKassa сериализуется строкой `yukassa_payments` (`FOR UPDATE`).
VK сериализуется ledger `payment_deliveries`, UNIQUE `(provider, external_id)`.

### Inventory

Pure recipe functions сначала валидируют полный catalog и существующий inventory, затем строят полный новый inventory без SQL writes. Repository adapters владеют locks и SQL transaction.

## Обнаруженные поздние compatibility defects

Эти дефекты показали, почему unit/искусственные fixtures недостаточны.

1. `rarity_id=0` — валидная базовая редкость (`Рунный булыжник`, `Пыль забвения`), но executor запрещал `<=0`.
   - Исправлено на `<0`.
   - Production получил только минимальный compiled hotfix этого условия.
   - Exact production mega catalog dry-run после hotfix: `ok=true`, DB writes 0.

2. Legacy equipment IDs создавались как `Date.now() + Math.random()`.
   - Production: 306 fractional IDs у 77 users.
   - Existing finite positive numeric IDs теперь допустимы.
   - Новые starter IDs остаются UUID-only.

3. Legacy `type:'upgrade'` stacks не имеют equipment `slot`.
   - Теперь валидируются как stack по integer nonnegative `count`.

4. SQL `NULL` inventory нельзя превращать в `[]`.
   - Serializer сохраняет `null`, pure recipe отклоняет non-array fail-closed.
   - Production сейчас: 0 NULL/non-array inventories.

5. Existing stack `count:'2'` раньше принимался через `Number()`.
   - Теперь raw count обязан быть `number`, integer, `>=0`.
